## 🚀 How to Run

### Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py

# Or use the run script
# Windows: run_flask.bat
# Linux/Mac: ./run_flask.sh
```

### Access the Application
```
http://localhost:5000
```
