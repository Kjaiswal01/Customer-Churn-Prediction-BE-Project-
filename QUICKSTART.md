# 🚀 Quick Start Guide

## Run Your Customer Churn Prediction Platform in 3 Steps!

### Step 1: Install Dependencies (if not already installed)
```bash
pip install -r requirements.txt
```

### Step 2: Start the Application
```bash
streamlit run app/streamlit_app.py
```

### Step 3: Open in Browser
The app will automatically open at: **http://localhost:8501**

If it doesn't open automatically, copy the URL shown in the terminal and paste it in your browser.

---

## 🎯 What You'll See

1. **🏠 Dashboard** - Overview with key metrics and quick insights
2. **🔮 Predict Churn** - Predict churn for individual customers
3. **📈 Analytics** - Comprehensive customer analytics and visualizations
4. **👥 Customer Insights** - Customer segmentation and risk analysis
5. **💡 Retention Actions** - Proactive retention strategies and templates
6. **📊 Bulk Analysis** - Upload CSV files for batch predictions

---

## ✨ Key Features

- **Modern, Beautiful UI** with gradient headers and interactive charts
- **Real-time Predictions** with risk scoring and recommendations
- **Customer Segmentation** by risk level (Low/Medium/High)
- **Actionable Insights** with personalized retention strategies
- **Bulk Processing** for analyzing multiple customers at once
- **Export Capabilities** to download predictions as CSV

## 📝 Notes

- Make sure you have trained the model first (run `python model_training.py`)
- The app requires model files in the `models/` directory
- All predictions are done in real-time using the trained ML model
